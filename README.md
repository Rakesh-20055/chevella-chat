# 💬 Chevella Chat

A real-time chat application built with Java, Spring Boot and MySQL.
Inspired by modern messaging apps, built from scratch for learning.

### ✨ Features
- One-to-one chat
- Group chat
- Delete For Me / Delete For Everyone
- Chat list with last message preview
- MySQL database storage
- Clean WhatsApp-style UI

### 🛠️ Tech Stack
- Java 17
- Spring Boot
- MySQL
- HTML / CSS / JavaScript
- Maven

### 🚀 How to Run
1. Clone this repo
   git clone https://github.com/Rakesh-20055/chevella-chat.git
2. Open in IntelliJ IDEA
3. Create MySQL database `chevella_chat`
4. Update username / password in `application.properties`
5. Run the project
6. Open browser -> http://localhost:8080
